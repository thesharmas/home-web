Agents API Overview

The OpenAI Agents API provides managed access to the Codex harness, handling sessions, orchestration, context compaction, and recovery while developers supply tools and choose execution environments. It is built around four core concepts—Agent, Environment, Session, and Events/Items—and supports capabilities like sandboxed code execution, MCP server connections, multi-agent delegation, and streamed output. The API currently supports data residency only in the US and does not support Zero Data Retention.
