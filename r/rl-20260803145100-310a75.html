Ep 179: Ethiopia's Value Recovery Instruments

This podcast episode examines value recovery instruments (VRIs) as used in sovereign debt restructuring, using Ethiopia as a case study. It outlines the recurring problems with VRIs—governments resist paying out, instruments end up with opportunistic investors, and poor drafting creates exploitable loopholes. The episode asks whether Ethiopia's latest attempt has finally found a workable structure for these instruments.
