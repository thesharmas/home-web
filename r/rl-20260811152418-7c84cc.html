Stealing Reasoning Traces from Proprietary LLM APIs

Researchers demonstrate that encrypted reasoning blocks returned by frontier LLM APIs (Anthropic, OpenAI, Google) can be extracted by injecting them into weaker, jailbroken models from the same provider, recovering the stronger model's hidden reasoning verbatim. Applying this pipeline to 6,708 publicly available agent trajectories on GitHub and Hugging Face, they reconstructed over 315,000 reasoning blocks and recovered 704 distinct privacy artifacts including API keys, passwords, access tokens, and personal data.
