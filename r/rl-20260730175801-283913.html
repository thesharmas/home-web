Mac log link - Shortcuts Workflow

This is a macOS Shortcuts workflow named 'Mac log link' that retrieves the current URL from Google Chrome's active tab using AppleScript, then sends it to a self-hosted Tailscale endpoint at /hooks/readlog. The workflow is configured as a Quick Action available in the Services Menu and Share Sheet, enabling the user to log the current browser URL to their personal reading log server with a single action.
