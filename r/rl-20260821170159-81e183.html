What happens when a GPU reads memory

The article traces the complete hardware journey of a single global memory load instruction (LDG.E) in a CUDA vector-add kernel running on an RTX 4090, from the warp's register file through the coalescer, L1 cache, TLB, crossbar, L2 cache, memory controller, and GDDR6X DRAM, and back. Each stage is explained in detail including latency measurements (L1 ~15 ns, L2 ~127 ns, DRAM ~255 ns) derived from microbenchmarks run on the hardware itself.
