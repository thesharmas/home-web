As a Windows user, it's a very surreal way to install a program

The article explores the macOS DMG drag-to-Applications install flow, explaining how developers use customized Finder windows with icon views, custom backgrounds, and arrows to guide users. The author curates and critiques a wide variety of these "drag to Applications" window designs, categorizing them by arrow style, layout direction, text instructions, visual scenes, gestalt issues, and overall aesthetics. Special attention is given to standout examples like Firefox and Inkscape, which crowdsources its installer backgrounds from the community.
