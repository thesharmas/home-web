What happens when you run a CUDA kernel

A detailed technical walkthrough tracing the full lifecycle of a simple CUDA vector-addition kernel on an RTX 4090, from compilation through nvcc (PTX → SASS → fatbin) to the host launch stub, pushbuffer/GPFIFO command stream, doorbell ring, and compute work distributor. It then covers how warps are scheduled on SMs using compiler-encoded control bits (stall counts, scoreboard barriers, yield hints), how memory coalescing works, and how results travel back to the CPU via a completion semaphore and PCIe DMA.
