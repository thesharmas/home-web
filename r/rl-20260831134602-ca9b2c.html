Agent memory as a file format

The article introduces 'Memoryfields', a simple portable file format for AI agent memory based on Markdown pages, optional YAML frontmatter, and an optional SQLite vector index. The author argues that existing agent memory systems are either too complex, too lock-in-prone, or strip context from information, and that memory is better represented as a data format (a zip of Markdown files) rather than a multi-stage pipeline.
