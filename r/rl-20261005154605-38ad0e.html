Inside-Out AI: Rebuilding Airbnb Behind the Scenes and Across the Guest Experience

Airbnb CTO Ahmad Al-Dahle, formerly head of generative AI at Meta, is leading an "inside-out AI" strategy: first using AI internally to accelerate product development (60% of code is AI-authored, 80% more features shipped YoY), then deploying those capabilities externally. Key internal tools include the Everest context graph, which helped cut development time for new services like grocery delivery and airport pickups, and AirChat, an internal agent with organizational context.
